# Live2D Studio

![](/images/docs/live2d-studio/sample.png)

## 它能做什么

- 隐藏`.moc3`文件的Part或者ArtMesh，比如背景不透明的Live2D模型，可以隐藏其背景。

- 给动作文件`motion3.json`添加声音和台词。

- 绑定`HitArea`，点击看板娘的不同位置，触发对应的动作。

- 修改模型参数并添加绑定，实现表情切换和换装。

- 烘焙功能将多个分散的`motion3.json`合并成一个文件，实现动作的连续播放。

- 将上述改动导出成Atlas支持的manifest清单，提供更人性化的交互。
