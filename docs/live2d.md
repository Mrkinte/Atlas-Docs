# Live2D

基于开源项目`oh-my-live2d`进行开发，如果想要给自己的模型指定开机动作、待机动作、语音、互动、台词等，请详见[Live2D Studio](/docs/live2d-studio)

::: tip 提示
仅测试过多款`.moc3`模型，未对早期版本的`.moc`模型进行测试。
:::
